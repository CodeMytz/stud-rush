## Setup
```bash
npm install
cp .env.example .env      # or copy your old .env
npm test                  # 21 Hardhat tests (offline: npm i --no-save solc@0.8.28 && SOLCJS=1 npm test)
npm run deploy:sepolia    # writes src/lib/deployment.json + abi.json
npm run dev               # local site
npm run build             # static site in dist/
```
`.env` (Hardhat only, never bundled): `PRIVATE_KEY`, `SEPOLIA_RPC_URL`, `SMART_CONTRACT` (STUD).

## Layout
`contracts/YieldArena.sol`, `contracts/DealTable.sol` (generated by `scripts/gen-deals.cjs`), `test/`, `src/` (Svelte). Publish `dist/` with GitHub Pages (workflow included) or Render.
